# Sample projects

A project is the handful of decisions a world is baked from, as JSON — see
*What a project is* in the [editor's README](../README.md). These open with

```bash
glisteel-editor samples/ashdown.glisteel
```

## `ashdown.glisteel`

A closed circuit of 21 points on the shipped procedural landscape, seed 11:
3.46 km, which the road generator carries over two bridges and through one
tunnel once it has settled the line onto the ground. The points are the shipped
circuit's own, thinned to the number a hand would put down.

It is what the documentation's picture of the editor is taken from, so that
picture can be produced again rather than fished for.
